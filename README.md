# XNL HR & Communications

Website for XNL HR & Communications (Newmarket, ON) — fractional HR + workplace mediation for Ontario SMBs and NFPs.

**Stack:** Next.js 16 (App Router) · React 19 · Tailwind v4 · TypeScript · Vercel

**Run locally:**

```bash
npm install
npm run dev
```

Open http://localhost:3000.

**Deploys** to Vercel on push to `main`.
